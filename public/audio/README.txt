# Folder Audio Statis (Public Audio Assets)
# ========================================================
# Taruh berkas lagu (.mp3 / .wav / .ogg) Anda di dalam folder ini!
# 
# Contoh:
# 1. Simpan lagu Anda di sini dengan nama: `seasons.mp3`
#    Path: `public/audio/seasons.mp3`
# 2. Buka web -> Masuk ke Chapter 3 (Vinyl Player)
# 3. Klik tombol "GANTI / EDIT LAGU INI" pada piringan vinyl yang diinginkan
# 4. Masukkan URL Audio: `/audio/seasons.mp3`
# 5. Simpan & Push ke GitHub / Vercel / Netlify!
#
# Hasilnya:
# Lagu ini akan otomatis TERBAWA dan BISA DIPUTAR oleh siapa saja (termasuk teman/gebetan)
# dari HP maupun laptop mereka tanpa perlu upload ulang!
